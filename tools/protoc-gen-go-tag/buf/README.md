# protoc-gen-go-tag

`tag.proto` declares the field option `field_tag`, which sets custom struct tags of fields in Go code generated by
[protoc-gen-go-tag](https://github.com/searKing/golang/tree/master/tools/protoc-gen-go-tag).

```yaml
# buf.yaml
version: v2
deps:
  - buf.build/searking/protoc-gen-go-tag
```

```proto
import "github.com/searKing/golang/tools/protoc-gen-go-tag/tag/tag.proto";

message Http {
  string protocol = 1 [(google.protobuf.field_tag) = {struct_tag: 'validate:"oneof=http https"'}];
}
```
