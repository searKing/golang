# protoc-gen-go-tag

`searking/tag/v1/tag.proto` declares the field option `field_tag`, which sets custom struct tags of fields in Go code
generated by [protoc-gen-go-tag](https://github.com/searKing/golang/tree/master/tools/protoc-gen-go-tag).

```yaml
# buf.yaml
version: v2
deps:
  - buf.build/searking-proto/protoc-gen-go-tag
```

```proto
import "searking/tag/v1/tag.proto";

message Http {
  string protocol = 1 [(searking.tag.v1.field_tag) = {struct_tag: 'validate:"oneof=http https"'}];
}
```
